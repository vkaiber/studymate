# Security Policy

## Supported versions

Security fixes are prioritized for the latest published StudyMate release.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature, if enabled for this repository. Include the affected version, impact, reproduction steps, and any relevant logs. Do not include personal study data.

## Security notes

- StudyMate is a local-first desktop application.
- Do not store passwords, API keys, or other secrets in notes or imported files unless you understand the risks of local device access.
- Download installers only from the repository's official Releases page.
- Release binaries may be unsigned; verify that the release is published by the expected repository owner.
