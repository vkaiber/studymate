# Contributing to StudyMate

Thank you for considering a contribution.

## Before you start

- Search existing issues before reporting a bug or proposing a change.
- For larger changes, open an issue first to discuss the scope.
- Keep pull requests focused and explain the user-facing impact.

## Development

1. Fork the repository.
2. Clone your fork.
3. Install dependencies with `npm install`.
4. Start the desktop development app with `npm run dev:desktop`.
5. Run `npm run build` before submitting changes.

## Pull request checklist

- [ ] The change has a clear description and rationale.
- [ ] Existing behavior has not been unintentionally removed.
- [ ] The app builds successfully.
- [ ] Relevant flows have been manually tested.
- [ ] Documentation is updated when behavior or setup changes.
- [ ] No secrets, personal data, build output, or `node_modules` are committed.

## Bug reports

Include your Windows version, StudyMate version, reproduction steps, expected behavior, actual behavior, and screenshots or logs when useful. Do not attach private notes or personal documents.
