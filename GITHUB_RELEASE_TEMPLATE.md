## StudyMate 6.1.4

A focused maintenance release for the StudyMate desktop app.

### Highlights
- Fixed global keyboard shortcuts interrupting note writing.
- Improved shortcut detection for editable fields.
- Updated project metadata and public repository documentation.

### Windows download
Attach `StudyMate-Setup-6.1.4-Windows-x64.exe` to this release after building and testing it on Windows 10/11 x64.

### Important
This repository source archive has been ZIP-validated. The Windows installer must be built and manually tested before the release is presented as a verified installer.

### Installation
1. Download the Windows x64 installer from the Assets section.
2. Run the installer.
3. Launch StudyMate from the Start menu or desktop shortcut.

### Data safety
Create an in-app backup before upgrading an existing installation.
